Phased Array Focal Law Calculator in the browser

Help for the browser version. Open the calculator

Nothing to install. The page runs the calculator's own Python inside your browser (through Pyodide). Nothing you type leaves your computer: the website only supplies the program's files, and all the calculation happens on your machine.

Opening it

  • Use a current Microsoft Edge, Google Chrome or Firefox.
  • The first visit takes about 20 seconds while the browser downloads and starts Python (about 30 MB). The status line under the buttons says Ready when it is done. Later visits are usually quicker, because the browser keeps the files.
  • It works only from the website. A copy of the files opened from a drive (file://) will not start; browsers do not allow it.

Using it

  1. Set up the probe, aperture, wedge, component and scan on the left. The defaults are the Evident 2.25L64-A2 probe on an SA2-N55S wedge, elements 1–32, in steel. Lengths are in mm, speeds in m/s.
    • Height at el. 1 is the height of element 1's centre above the wedge's contact face.
    • Offset X el. 1 is element 1's X position.
    • Depth / path / X is the focal depth, the sound path or the vertical line's X, depending on Focus.
  2. Press Calculate laws. The table lists every law: its angle, focus and delay range. A law that cannot be made (beyond a critical angle, or a focus above the surface) is listed with its reason instead of numbers.
  3. Choose a law with the slider or by clicking its row. The Ray tracing X-Z view shows the elements (red: active), rays to the focus (+) and the other laws' foci (light blue). Delays shows each active element's delay in microseconds.
  4. Press Beam field for the selected law's beam in the component: a map in dB below its strongest point, 0 to −30 dB, with the −6 dB contour in white.
    • Pulse: a Hann burst of Cycles (whole cycles, 2 or more), or Continuous wave, which is faster.
    • Grid: the map's spacing. A large area is coarsened automatically to 40 000 points.
    • It takes a few seconds; the page waits while it computes.
  5. If you change an input, the laws or the map no longer match it. The map fades and says it is stale; press Calculate laws (for setup changes) or Beam field again.

The beam field: what it is and is not

A ray model of the direct beam through a bonded wedge: each element's directivity, transmission into the component, and beam spread, added with the law's delays. It leaves out reflections (back wall, surface), mode conversion, attenuation and a couplant layer. It was checked against a finite-element solve (a 45° shear beam: angle within 0.4°, width within 0.6 %); other cases are not yet checked. Use it for where the beam goes and how wide it is, not for absolute amplitudes. The full model note says how it is computed and where it can be trusted.

What the browser version does not do yet

It is a first version. Use the desktop window (or ask) for:

  • matrix and dual probes, skew and Y sweeps, roof angles;
  • opening probe and wedge catalogues;
  • saving or loading configurations, and CSV export of the laws;
  • coverage fans and skips, welds and DXF files;
  • the 3D view and the 3D beam field.

If it does not work

What you seeLikely causeWhat to do
Stuck on Loading Python in the browser… The download is slow or blocked, or the browser is old Wait a minute on a slow network; reload. Try Edge or Chrome. If it never loads at work, the network may block the site: tell the owner, who can host it on the work network instead.
Could not start Python: … Usually the browser's policy disables WebAssembly, or the page was opened from a drive Open it from the website address. If the message mentions WebAssembly, the browser policy blocks it: tell the owner.
Error: … after CalculateAn input the calculation refuses (for example a speed of 0) Read the message; it names the problem. Correct the input and calculate again.
