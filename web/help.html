Focal Law Calculator in the browser

Help. Open the calculator

Nothing to install, nothing sent. The page runs the calculator's own Python inside your browser (through Pyodide): the same code as the desktop calculator. The website only supplies the program's files; the files you open (configurations, catalogues, DXF drawings) are read in your browser, and what you save is downloaded from it. Nothing you enter leaves your device.

Opening it

  • Use a current Edge, Chrome, Safari or Firefox, on a computer, tablet or phone.
  • The first visit takes about 20 seconds while the browser downloads and starts Python (about 30 MB; less on later visits, which use the browser's cache). The line under Calculate laws says Ready when done.
  • It works only from the website. A copy of the files opened from a drive (file://) will not start.

Layout

  • Setup holds the inputs, in sections you open and close: Probe, Wedge, Component, Scan, Active aperture, Weld and Beam field. On a wide screen it is on the left. On a phone it slides in from the ☰ button and closes after you press Calculate laws.
  • Tabs: Rays, Laws, Delays and Beam field.
  • The law bar at the bottom: ◀ ▶ step through every law, the Angle slider (and Skew for matrix probes) picks one, ▷ plays the sweep.
  • File (top right): open and save configurations, load a probe or wedge from a catalogue, export the laws or the element coordinates.
  • Plots: drag to pan, scroll or pinch to zoom, double-click (double-tap) to reset.

Setup

The inputs are the desktop calculator's, with the same names, units and rules (lengths in mm, speeds in m/s). Fields appear only when they apply: the passive (Y) elements and pitch, the skew range, Y focus modes and element order for matrix probes; the array separation and roof angle for dual probes; each weld type's own dimensions.

  • Material (wedge and component) fills the speeds from a short list; choose Custom to type your own.
  • Height at el. 1 is the height of element 1's centre above the contact face; Probe offset X is element 1's X position.
  • Scan: the focus type sets the meaning of the last field (target depth, the vertical line's X, or the focal distance along the beam). Matrix probes add skew and the Y focus mode (from skew, a fixed Y, or a Y sweep); a fixed Y is not offered with a constant sound path.
  • Active aperture: the first element and how many (0 = all); for matrix probes, whether element numbers run column-first or row-first.
  • Weld: none, a Single-V, Double-V or Single-J preparation, or a DXF file of the weld's cross-section (x = 0 at the weld centreline, y up; say whether y = 0 is the surface or the backwall; units from the file or set here; a layer name when the file holds more than one outline). The component Thickness must be set. A DXF file is read in your browser; the first one takes a few extra seconds while the DXF reader loads.
  • Beam field: the inputs for the Beam field tab (see below).

If you change an input after calculating, press Calculate laws again; the views and a computed beam field are marked out of date until you do.

The tabs

Rays

  • The X-Z section (and Y-Z for matrix and dual probes): wedge, elements (red active, grey inactive; Tx blue and Rx red for dual probes), the selected law's rays and interface points, its focus (red +) and every law's focus (light blue).
  • Move the focus: drag the red circle on the X-Z view, or press Place focus and tap where the focus should be (easier on a phone). The law for that point is solved and shown everywhere; it is not added to the table or the CSV. The sliders, steps or a table row return to the sweep.
  • Tap an element for its number, delay and time of flight (also shown in Delays).
  • Coverage: the sweep's central rays through a flat plate of the component Thickness with skips (Direct, + 1st skip, + 2 skips), drawn as fans, and the current law's central ray dashed. Each reflection keeps the wave mode and only central rays are shown, not the beam's spread. With a weld, its fusion faces are green where a fan reaches them and red at gaps, and the note under the plot gives the share covered.
  • Show all laws overlays every law's outer rays, coloured by angle.

Laws

Every law: angle, skew, focus (X, Y, Z) and its delay range. A law that cannot be made (beyond a critical angle, a focus above the surface, a beam parallel to the target line, a Y out of reach) is listed with its reason. Tap a row to show that law.

Delays

Each element's delay for the law shown: bars for linear and dual linear probes (inactive elements marked ×), a map per array for matrix probes. Tap a bar or cell for that element.

Beam field

Press Compute beam field for the beam of the law shown (or of a moved focus), as a map in dB below its strongest point (0 to −30 dB) with the −6 dB contour in white, the focus (+) and the fitted beam axis.

  • Model: 2D treats each element as an infinitely long strip and maps the X-Z section (single linear arrays). 3D uses each element's width and elevation and also maps the Y-Z section through the focus.
  • Pulse: a Hann burst of whole Cycles (2 or more), or a continuous wave (faster). Grid: the map spacing; large areas are coarsened automatically.
  • Element width, Elevation, the wedge's S-wave speed and density, and the component density are filled from a catalogue when the probe or wedge comes from one.
  • It takes a few seconds (a 3D map longer); the page waits while it computes.

What the beam field is and is not. A ray model of the direct beam through a bonded wedge: each element's directivity, transmission into the component and beam spread, added with the law's delays. It leaves out reflections, mode conversion, attenuation and a couplant layer. Checked against a finite-element solve for a 45° shear beam (angle within 0.4°, width within 0.6 %); other cases, and the 3D mode, are not yet checked. Use it for where the beam goes and how wide it is, not for absolute amplitudes. The model note explains it in full.

Files

File menuWhat it does
Open / Save configurationThe desktop calculator's configuration files (JSON): a file saved here opens in the desktop calculator and the other way round. Catalogue references travel with it. A DXF weld's file is not stored in the configuration: open it again (Setup > Weld) after loading.
Load probe / wedge from catalogueOpen a buildFE or nde-knowledge catalogue file (JSON), pick an entry; its values fill the panels and a summary says what came from where and what is missing.
Export laws (CSV)The focal-law CSV, as the desktop calculator writes it: one row per law, each element's delay in µs.
Export element coordinatesThe elements' global coordinates (mm) as CSV, a MATLAB script or a MAT file.

If it does not work

What you seeLikely causeWhat to do
Stuck on Starting Python… The download is slow or blocked, or the browser is old Wait a minute on a slow connection, then reload. Try another current browser. If it never loads at work, the network may block the site: tell the owner, who can host it on the work network instead.
Could not start Python: … Usually the browser's policy blocks WebAssembly, or the page was opened from a drive Open it from the website address. If it mentions WebAssembly, the browser policy blocks it: tell the owner.
Not a number: … or Error: …An input the calculation refuses The message names it, and the field turns red. Correct it and calculate again.
